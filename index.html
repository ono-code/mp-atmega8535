ARSITEKTUR RISC 8-BIT

Mikrokontroler AVR ATmega8535

ATmega8535 adalah mikrokontroler CMOS 8-bit berdaya rendah berbasis arsitektur AVR Enhanced RISC. Karena kemampuannya mengeksekusi hampir satu instruksi per siklus clock (hingga 16 MIPS pada kristal 16 MHz), IC ini menjadi standar utama praktikum kendali robotika di SMK Teknik Elektronika Industri.

Spesifikasi Utama Perangkat Keras:

  • Memori Program: 8 KB In-System Programmable Flash (tempat menyimpan file .hex hasil kompilasi BASCOM-AVR).
  • Memori Data: 512 Byte SRAM (untuk variabel saat program berjalan) & 512 Byte EEPROM (penyimpanan permanen).
  • 32 Jalur I/O Terprogram: Terbagi menjadi 4 Port 8-bit yaitu PORTA, PORTB, PORTC, dan PORTD.
  • ADC Internal: 8 kanal ADC 10-bit (resolusi 0–1023) terintegrasi pada PORTA (Pin 33–40).
  • Timer & PWM: Dua Timer/Counter 8-bit (Timer0, Timer2) dan satu Timer/Counter 16-bit (Timer1 dengan output PWM OC1A & OC1B).

STRUKTUR & REGISTER I/O

Anatomi Program BASCOM-AVR

BASCOM-AVR menggunakan sintaks bahasa BASIC yang terstruktur dan mudah dipahami. Setiap program kendali robot memiliki 3 bagian wajib: Header Direktif, Inisialisasi I/O & Variabel, serta Program Utama (Main Loop).

Aturan Emas PORTx vs PINx (Sering Keliru!)

  • 1. Menentukan Arah (Input/Output): Gunakan Config Portb = Output atau register DDRB = &B11111111 (1 = Output, 0 = Input).
  • 2. Mengirim Data Keluaran (Output): Gunakan kata kunci PORT. Contoh: Portb.0 = 1 (menyalakan aktuator/LED pada PB0).
  • 3. Membaca Data Masukan (Input): Gunakan kata kunci PIN! Contoh: If Pina.0 = 0 Then... (membaca tombol atau sensor digital pada PA0).
  • 4. Resistor Pull-Up Internal: Saat pin menjadi Input, aktifkan pull-up dengan Porta = &B11111111 agar logika tidak mengambang (floating).
dasar_io_robot.bas 
' 1. BAGIAN HEADER DIREKTIF KOMPILER
$regfile = "m8535.dat"      ' Gunakan pustaka IC ATmega8535
$crystal = 16000000         ' Frekuensi kristal eksternal 16 MHz

' 2. KONFIGURASI ARAH PORT I/O
Config Porta = Input        ' Port A sebagai input sensor/tombol
Config Portb = Output       ' Port B sebagai output LED/aktuator
Porta = &B11111111          ' Aktifkan internal pull-up Port A

' 3. DEKLARASI ALIAS PIN AGAR MUDAH DIBACA
Tombol_start Alias Pina.0   ' Baca input pakai PINA.0
Led_indikator Alias Portb.0 ' Tulis output pakai PORTB.0

' 4. PROGRAM UTAMA (PERULANGAN ABADI)
Do
   If Tombol_start = 0 Then ' Tombol aktif rendah (Active Low)
      Led_indikator = 1     ' Nyalakan LED (Logika HIGH / +5V)
      Waitms 200            ' Tunda 200 milidetik
   Else
      Led_indikator = 0     ' Matikan LED (Logika LOW / 0V)
   End If
Loop
End
AKUSISI DATA SENSOR

Sensor Garis Inframerah & ADC 10-Bit

Robot Line Follower menggunakan pasangan LED Superbright / Inframerah dan Photodiode untuk membedakan pantulan cahaya lantai putih dan garis hitam. Tegangan analog dari sensor masuk ke pin PORTA.0 s.d. PORTA.7 untuk diubah menjadi angka digital oleh modul ADC (Analog-to-Digital Converter).

Rumus Konversi ADC 10-Bit (Vref = 5V):

Nilai ADC = (Vin / 5.0 Volt) × 1023
Lantai Putih (Pantulan Kuat) Photodiode menghantar → Vin rendah (±0.6V) → ADC ≈ 120
Garis Hitam (Cahaya Diserap) Photodiode menahan → Vin tinggi (±4.2V) → ADC ≈ 860

Dengan nilai ambang batas (threshold) misalnya 500, program dapat memutuskan secara akurat apakah sensor menyentuh garis hitam (Nilai_adc > 500) atau lantai putih!

baca_sensor_adc.bas 
$regfile = "m8535.dat"
$crystal = 16000000

' Konfigurasi Modul ADC Internal
Config Adc = Single , Prescaler = Auto , Reference = Avcc
Start Adc                   ' Aktifkan periferal ADC

Config Portb = Output       ' Indikator LED hasil pembacaan

' Variabel Word (0 s.d. 65535) wajib untuk ADC 10-bit (0-1023)
Dim Sensor_kiri As Word
Dim Sensor_kanan As Word

Do
   Sensor_kiri = Getadc(0)  ' Baca tegangan analog pada PA0
   Sensor_kanan = Getadc(1) ' Baca tegangan analog pada PA1

   ' Bandingkan dengan nilai ambang (Threshold = 500)
   If Sensor_kiri > 500 Then
      Portb.0 = 1           ' Sensor kiri mendeteksi garis hitam
   Else
      Portb.0 = 0           ' Sensor kiri di atas lantai putih
   End If
Loop
End
AKTUATOR & MODULASI LEBAR PULSA

Driver Motor L298N & PWM Timer1

Pin mikrokontroler ATmega8535 hanya mampu menyuplai arus maksimal ±20 mA, sehingga tidak boleh dihubungkan langsung ke motor DC. Kita menggunakan IC Driver H-Bridge L298N untuk mengatur arah putaran (Clockwise / Counter-Clockwise) dan sinyal PWM (Pulse Width Modulation) pada pin PD5 (OC1A) dan PD4 (OC1B) untuk mengatur kecepatan putaran motor.

ENA (PWM) IN1 IN2 Kondisi Motor DC
1 - 255 1 0 Berputar Maju (CW)
1 - 255 0 1 Berputar Mundur (CCW)
0 / X 0 0 Berhenti Bebas (Stop)
255 1 1 Rem Aktif (Fast Brake)
kendali_pwm_motor.bas 
$regfile = "m8535.dat"
$crystal = 16000000

' Konfigurasi Timer1 sebagai Pembangkit PWM 8-Bit (0 - 255)
' Output otomatis keluar di PD5 (OC1A) dan PD4 (OC1B)
Config Timer1 = Pwm , Pwm = 8 , Compare A Pwm = Clear Up , Compare B Pwm = Clear Up , Prescale = 64

Config Portb = Output       ' PB0..PB3 ke pin IN1..IN4 Driver L298N

Do
   ' Gerak Maju Kecepatan Sedang (Duty Cycle ~78% -> 200/255)
   Portb = &B00001010       ' Motor Kiri Maju (10), Motor Kanan Maju (10)
   Pwm1a = 200              ' Kecepatan Motor Kiri (Pin PD5)
   Pwm1b = 200              ' Kecepatan Motor Kanan (Pin PD4)
   Wait 2

   ' Belok Kanan Tajam (Kiri Cepat, Kanan Pelan/Stop)
   Pwm1a = 220
   Pwm1b = 60
   Wait 1
Loop
End
